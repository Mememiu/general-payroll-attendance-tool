# 升级与恢复

1. 关闭 App，并确认窗口已经退出。
2. 在 App 的“高级设置”导出规则备份 ZIP，同时备份已经下载的工资结果。
3. 下载新版本并覆盖旧应用程序；不要删除用户数据目录。
4. 启动新版本。App 会检查 `data-version.json`，需要迁移时先把数据库复制到 `backups/`，成功后才更新版本标记。
5. 核对规则版本、计算记录和一份历史结果，再开始新月份计算。

如果启动提示数据版本高于应用支持版本，说明安装了旧版本，请重新安装较新的版本。迁移失败时不要修改 SQLite 文件，把错误信息和 `backups/` 目录位置提供给维护者；工资明细文件不需要上传。

完整人工备份可在 App 关闭后复制整个 `GeneralPayrollTool` 数据目录。恢复时先保留当前目录副本，再把备份恢复到原位置。
