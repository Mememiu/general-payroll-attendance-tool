# 本地 App 与数据安全设计

## 交付形态

应用打包为 macOS 和 Windows 独立安装包，启动本机服务并打开系统浏览器或桌面壳。默认仅监听 `127.0.0.1`，其他电脑无法访问。每位用户在自己的电脑安装运行，与开发者电脑无依赖。

## 本地存储

规则包、任务、上传文件、计算结果和日志保存在应用数据目录，不写入源码目录。规则包支持本地保存、复制、版本发布、导入和导出；政策变化应复制新版本并设置新生效日，历史任务继续引用旧版本。

## 安全

敏感文件不上传网络；临时文件及时清理；导出目录由用户选择。应用提供本地备份和恢复，备份包含版本清单和校验值。日志只记录必要元数据，不记录工资明细正文。

## GitHub 边界

仓库只包含通用代码、空白模板、虚构测试数据和开发文档。真实公司规则、员工考勤、薪资结果和本地数据库必须由忽略规则排除，并在发布前执行仓库敏感信息扫描。

## 更新

离线版本不强制联网。升级前自动备份；数据库和规则模板迁移必须可回滚。macOS 和 Windows 分别进行安装、启动、文件上传、导出、中文路径和大文件测试。
