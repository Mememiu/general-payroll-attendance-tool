# 通用薪酬绩效工具总需求

## 1. 产品定位

本产品是本地离线运行的通用薪酬与考勤计算工具。数据在用户电脑本地处理，支持 Windows 和 macOS；第一阶段以 HR 单机使用为主，不依赖地区接口、云数据库或在线账号。产品不携带任何公司的生效考勤规则，所有制度通过 HR 规则包输入并按版本保存。

## 2. 核心范围

系统覆盖计薪周期选择、考勤 XLSX 导入、薪酬主数据导入、HR 规则包配置、考勤文本解析、审批与打卡时段拼接、薪酬计算、五险公积金及商业保险、年度累计个税、异常复核、结果导出和审计追溯。绩效评分不纳入第一阶段计算范围，但页面和输出结构应允许后续扩展。

## 3. 业务链路

```text
选择计薪月份/起止日
  -> 导入并校验规则包
  -> 导入考勤 XLSX 与薪酬主数据
  -> 工号唯一匹配
  -> 解析每日考勤结果与审批时间线
  -> 生成每日明细和异常清单
  -> HR 处理异常或确认豁免
  -> 计算工资、扣款、奖金补贴、社保、公积金、商业保险、个税
  -> 导出结果与审计明细
```

## 4. 一致性原则

- 每日标准工时、计薪天数、班次、午休、迟到和加班规则只取当前生效 HR 规则包。
- 工时统一按整数分钟计算；金额最终按规则包舍入配置处理。
- 工号是主匹配键，姓名仅作展示和复核，不能用于自动替代工号匹配。
- 任一关键规则缺失、工号重复、员工无法匹配、考勤单元格无法解释或个税累计数据不足时，阻断正式出薪并生成异常清单。
- 每次计算记录规则包版本、输入文件指纹、计算时间、公式方案和人工覆盖。

## 5. 角色

HR 管理员负责规则包、员工主数据和工资输入；复核人员负责处理异常和人工调整；普通使用者只能查看或导出被授权的计算任务。第一阶段可不做账号系统，但页面必须保留权限边界，避免将本地工具误认为多人在线系统。

## 6. 结果范围

员工结果至少包括工号、姓名、用工类型、有效出勤天数、有效工时、各类假期时长、迟到/早退/旷工、考勤扣款、病假扣款、加班时长、加班费、调休余额、基本工资、奖金、补贴、员工扣款、单位成本、个税、实发工资和复核状态。结果应能追溯到每日明细，不允许只给一个无法解释的总数。

## 7. 验收基线

必须覆盖：HR 输入任意大于 0 且精确到分钟的每日标准工时，并确保考勤满勤、缺勤、请假扣款和薪资折算全链路使用同一输入值，不设置固定工时档位；同时覆盖固定和弹性制度、多休息段、外出/出差返岗截断、跨午夜加班、实习生和实习转正、入离职日、HR 配置的社保缴纳截止规则、员工奖金补贴计税但不影响五险一金、个税非首月累计数据缺失、相同姓名不同工号、重复工号、单卡和未知审批。

## 8. 非目标

第一阶段不自动联网查询社保政策，不上传员工数据，不执行任意 Excel/Python 公式，不把绩效评分计算混入工资，不提供无人审核的批量自动修正规则。
