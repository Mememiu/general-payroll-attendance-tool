# 公开仓库 README 界面展示设计

## 目标

在公开仓库 README 首页直接展示两张不含员工或公司数据的真实 App 界面截图，让访问者无需安装即可了解规则配置界面。

## 展示方式

- 在项目简介之后、详细文档链接之前新增“界面预览”章节。
- 两张截图纵向全宽排列，避免并排缩放导致界面文字难以辨认。
- 截图标题分别为“规则配置总览”和“公司制度配置”。
- 图片存放在 `docs/images/`，README 使用仓库相对路径引用，确保 GitHub 和本地预览都能显示。

## 图片处理

- 保留完整界面，不裁切关键区域。
- 使用适合 GitHub 加载的 PNG 尺寸，并保持文字清晰。
- 发布前再次扫描图片和 README，不得包含员工、考勤、薪酬或本机路径等隐私信息。

## 验收

- README 中两张图片链接有效。
- 图片按指定顺序展示，标题准确。
- 仓库隐私扫描和文档检查通过。
