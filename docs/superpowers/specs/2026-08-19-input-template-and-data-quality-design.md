# 输入模板与数据质量设计

## 输入文件

第一阶段固定支持 XLSX：考勤文件、薪酬主数据、HR 规则包、可选个税累计数据和可选人工调整表。每个模板包含“数据”“字段说明”“枚举值”“示例”工作表；示例行必须明确标注为示例，不能被读取为员工。

## 考勤文件契约

考勤文件必须包含工号、姓名、日期和“每日考勤结果”；关联审批单可存在但只作校验，不能覆盖每日考勤结果。系统保留原始单元格、文件名、工作表、行号和列名。日期必须可解析为自然日，工号按字符串读取以避免前导零丢失。

## 薪酬与规则包契约

薪酬主数据必须包含工号、用工类型、薪资方案及方案所需参数；奖金和补贴允许空值，空值按 0 处理。HR 规则包必须包含模板版本、规则包编号、生效日、考勤制度、假勤类型、加班、薪资方案、保险、税制和舍入策略。业务数值留空时不得静默使用旧公司的默认值。

## 分层校验

导入分为格式校验、字段校验、语义校验和交叉校验。格式校验检查 XLSX、工作表和表头；字段校验检查类型、空值和百分比范围；语义校验检查时间顺序、公式参数和枚举；交叉校验检查每日标准工时与班次可用时长、工号匹配、规则生效期和个税累计数据。

## 错误处理

错误按“阻断计算”和“允许人工复核”分类。阻断错误包括规则缺失、重复工号、未知用工类型、关键字段类型错误、同一员工多条冲突薪资和非首月个税累计缺失。单卡、未知审批、无法配对的跨午夜记录可以进入人工复核，但不能在未确认前生成正式工资。

## 导入预览

上传后显示文件摘要、识别行数、工号匹配率、重复项、未知项、规则版本和阻断原因。用户确认的每个文件保存 SHA-256 指纹；重新计算时若文件或规则版本变化，必须重新预览并提示差异。

## 模板版本

模板版本与规则包版本分开。模板升级不得改变旧规则包的含义；旧模板只能在明确迁移后使用。下载模板失败时页面必须提供本地生成和备用下载入口，并显示生成失败原因，不允许出现无响应按钮。

## 验收案例

工号 `0012` 必须保持字符串；考勤文件的姓名变化不影响匹配；“每日考勤结果”缺失而只有关联审批单时阻断；未知假期类型在规则包中未定义时阻断；空奖金显示 0；百分比输入 `2.6908%` 可解析为 Decimal 并保留审计原值。
