# 年度累计个税设计

## 政策

中国大陆模式按版本化累计预扣税率表、速算扣除数和基本减除费用执行。HR 选择政策版本，不允许修改法定参数后仍标记为法定版本。其他税制后续独立扩展。

## 输入

员工需提供本年累计收入、累计减除费用、累计专项扣除、累计专项附加扣除、累计其他依法扣除和累计已预扣税。当前月专项附加扣除提供员工输入接口。

## 阻断规则

非本年度首次计薪且缺少历史累计数据时阻断，不能自动按 0。明确标记本年首次计薪时才允许初始化。当前月税额计算结果小于 0 时按 0，历史多缴进入后续月份或年度汇算。

## 审计

结果保存政策版本、累计基数、税率档、速算扣除数、本月应扣和累计已扣。奖金若采用单独计税政策，必须作为独立受控方案并带适用年度。
