# 深圳养老保险基数参考

- 来源：广东省人力资源和社会保障厅，《关于公布2025年职工基本养老保险缴费基数上下限和基本养老金计发基数有关问题的通知》（粤人社发〔2025〕32号）。
- 公告链接：https://hrss.gd.gov.cn/zwgk/gsgg/content/post_4789648.html
- 发布日期：2025-10-24。
- 适用时间：企业职工基本养老保险缴费基数自 2025-07-01 起。
- 已核验值：基数上限 27549 元；除广州、省直外其他地区基数下限 4775 元（深圳适用此项）。
- 未核验内容：户籍费率、地方补充养老费率、个人账户记入口径。未获得对应官方来源前，不得写入可启用配置包。
