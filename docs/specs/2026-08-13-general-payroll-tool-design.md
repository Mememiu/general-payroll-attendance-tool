# 通用薪酬绩效工具产品设计

## 产品定位

本项目是可分享的本地离线薪酬与考勤计算工具。每位 HR 在自己电脑上运行、计算和导出，不依赖云服务器，不存储或传输企业工资数据。首期仅面向中国大陆固定工时企业，不宣称对所有国家、税法和考勤制度通用。

## 独立边界

- 使用全新 Git 仓库，不引入当前定制工具的 Git 历史。
- 不迁移任何真实考勤、薪酬、导出结果、员工工号、公司专属制度文档或本地路径。
- 测试仅使用人工构造数据，且不可与真实员工重新关联。
- 当前定制工具不做重构、不更改业务规则、不更改打包产物。

## 首期能力

1. 通过公司配置包定义工时、午休、迟到早退、加班、外出、出差和假别口径。
2. 通过薪酬方案配置定义正职、实习、转正人员的计薪公式、全勤奖、扣款和补贴奖金口径。
3. 内置中国大陆个税年度累计预扣模块，将其与其他地区税法模块解耦。
4. 支持公司级、员工级五险一金基数和费率配置，默认不预设任何城市、年度或人员档位。
5. 提供 Excel 字段映射、导入校验报告、结果导出和计算审计报告。
6. 每次计算记录配置版本、规则版本、输入文件指纹和计算时间，但默认不保存工资明细。

## 架构

```text
Desktop App
  -> Import Adapters (Excel mappings)
  -> Attendance Engine (normalized time segments)
  -> Payroll Engine (employment/pay plan)
  -> Statutory Modules (social insurance/tax)
  -> Export + Audit Report

Company Configuration Package
  -> attendance_policy.yaml
  -> payroll_plan.yaml
  -> social_insurance_plan.yaml
  -> import_mapping.yaml
```

考勤引擎、薪酬引擎和法定计算模块不读取 UI 字段名称。Excel 字段只在导入适配层转为标准数据模型。任何无法匹配的列、日期、人员或时段均必须返回可见错误，不得默认按零计算。

## 配置原则

- 规则以 YAML/JSON 配置包交付，每个包含 `id`、`版本`、`适用区域`、`生效日`和校验规则。
- 结果文件必须写入规则包 ID/版本和计算时间。
- 补贴、奖金、其他收入是独立收入项，其是否计税、是否计入社保公积金基数必须由配置显式声明。
- 五险一金模块默认为“未配置”，不使用任何隐含费率或基数。HR 必须明确填写地区、生效期、个人/单位费率、基数上下限、工伤行业档次以及公积金规则，系统才允许计算。
- 地方空表单与模板不等同于默认政策。任何带地区的示例包必须标明地区、生效时间、审核来源、医保档位和工伤档次；如缺养老保险或公积金规则，不得用于实际计算。
- 社保规则必须支持人员分类维度。例如深圳养老保险模板需区分深圳户籍与非深圳户籍：两类个人费率均为 8%，非深户单位费率为 16%，深户单位费率为 16% + 1% 地方补充养老。已核验的官方基数来源为《关于公布2025年职工基本养老保险缴费基数上下限和基本养老金计发基数有关问题的通知》（粤人社发〔2025〕32号，2025-10-24 发布）：企业职工养老基数自 2025-07-01 起上限 27549 元，深圳适用“其他地区”下限 4775 元。该公告不包含户籍费率和地方补充养老费率，这些费率在获得对应官方来源前仅作待审核参考，不得启用。
- 提供例子配置包，不提供任何实际公司配置。

## 隐私与安全

- 首期为本地离线 App，仅监听 `127.0.0.1`，不提供云端同步、遥测或自动上传。
- 导入的工资文件和中间结果默认存于本机临时目录，关闭 App 后清理。
- 每次计算、预览、核查和导出只能使用当次任务中由用户上传的考勤文件与薪酬主数据。系统不得从示例目录、项目目录、历史任务目录或其他本机文件补读数据。
- 每次任务在结果中记录上传文件名称、SHA-256 指纹、规则包版本和计算时间，供 HR 核查结果与上传文件的对应关系。
- 审计日志只记录操作类型、时间、规则版本、文件哈希和结果哈希，不写入员工姓名、工号、工资或完整打卡文本。
- 仓库忽略所有 Excel、CSV、日志、本地输出和密钥文件。将增加提交前密钥/大文件检查。

## GitHub 准备

- 初始使用 GitHub 私有仓库。
- 仓库包含 `README`、`CHANGELOG`、`SECURITY`、`CONTRIBUTING`、版本流程和 GitHub Actions CI。
- CI 运行单元测试、类型/语法检查、配置模式校验和敏感文件检查。
- 发布使用 GitHub Releases；面向其他 Mac 分发前，使用 Apple Developer ID 签名、公证和 DMG 安装包。

## 非目标

- 首期不提供多人云端协作、员工自助查薪或网页公网访问。
- 首期不覆盖全球税法、所有考勤厂商格式或所有用工制度。
- 首期不绕过签名、公证和权限设计将 HR 版直接分发给普通员工。

## 验收标准

1. 从空仓库克隆后，不含任何 Excel、真实员工标识符或当前项目路径。
2. 例子配置和合成测试数据可完整跑通考勤、薪资、个税和导出流程。
3. 任何无法解析的字段或配置都阻止计算并输出明确校验报告。
4. 每个结果可回溯到输入哈希、规则包版本和计算版本。
